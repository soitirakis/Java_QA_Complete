# Java QA Automation Portfolio

[![UI Tests](https://github.com/soitirakis/Java_QA_Complete/actions/workflows/run-tests.yml/badge.svg)](https://github.com/soitirakis/Java_QA_Complete/actions/workflows/run-tests.yml)

A self-taught QA engineer's journey through test automation — from Java fundamentals to a fully fledged Selenium framework with CI/CD and live reporting.

**🛠 Tech Stack:** Java 21 · Selenium 4 · TestNG · Maven · Allure · GitHub Actions

---

## 🚀 Featured Project — [Thinking Tester Automation Framework](Week11/thinking-tester-final)

End-to-end UI test automation framework for the [Thinking Tester Contact List](https://thinking-tester-contact-list.herokuapp.com/) app, built with:

- **Page Object Model** with a shared `BasePage` and explicit-wait utilities
- **Data-driven tests** — JSON test data mapped to POJOs (Jackson)
- **TestNG** suites covering positive and negative flows (login, sign-up, contact CRUD)
- **GitHub Actions CI** — every change runs the full suite in headless Chrome on Ubuntu
- **Allure reporting** — results published automatically to GitHub Pages

📊 **[Live Allure Report](https://soitirakis.github.io/Java_QA_Complete/)** · 🔧 [CI Workflow](.github/workflows/run-tests.yml)
